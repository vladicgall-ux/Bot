# Yandex Surf Bot

Telegram-бот для серфинга в Яндексе.

## Переменные окружения
- BOT_TOKEN — токен бота
- PROXY_LIST — прокси (server|user|pass), по одному на строку
- ADMIN_CHAT_ID — chat_id для отчётов
- AUTO_INTERVAL_HOURS — интервал автопрогона (по умолчанию 2)
- AUTO_ENABLED — true для автозапуска
